Latest release: v0.1.0-alpha.1, an experimental pre-release published November 25, 2026 (UTC). Release notes on GitHub.

⚠️ READ FIRST — experimental alpha, safety and radio warnings

  • EXPERIMENTAL ALPHA — NOT VALIDATED ON A PHYSICAL RASPBERRY PI. The public packages, installer and source tree have not been installed or accepted on a clean physical Raspberry Pi. Treat every package and every asset as experimental. Do not rely on T.A.S.K. as your only tool in a real emergency. It is not a substitute for emergency services.
  • RECEIVE-ONLY BY DEFAULT. T.A.S.K. must never transmit on any radio unless a licensed operator explicitly tells it to. Amateur transmit stays disabled until you enter your own licensed callsign. Transmit-capable features are experimental. Do not transmit if you are not licensed and allowed to. You are responsible for knowing the law where you are.
  • NO AUTOMATIC INSTALL, FIRMWARE FLASHING OR SERVICE START. The installer is a dry run only. It never flashes firmware, never takes control of your radios, and never starts anything automatically.
  • UNVERIFIED — REQUIRES PHYSICAL HARDWARE TEST. Any radio, GPS, SDR, board or feature not listed as tested in HARDWARE.md carries this label. Test on a spare SD card, never on a working system.

Read SAFETY.md and KNOWN-ISSUES.md before you install anything. See also the safety summary on this site.

Verify your download

Do this before you unpack or install anything. Put the files you downloaded and SHA256SUMS in the same folder, open a terminal there, and run:

sha256sum -c SHA256SUMS

Every file listed must print OK. If any file prints FAILED, do not use it: download it again, or stop and file an installation-problem issue. If you downloaded only some of the files, sha256sum will also complain about the missing ones; the GNU option --ignore-missing skips them.

No SHA256SUMS file handy? Compare a single file by eye with the values above:

sha256sum TASK-volunteer-test-debs-20261123.zip

The 64-character value must match exactly:
ba50f7de2e599023e60f0c186a9de144a708ffd6ff83c88a61ee0f508a0fbf4e

Checksums protect against corrupted or tampered downloads. They are not a guarantee that the software is safe or validated: it is an experimental alpha.

System requirements

What you need

  • A Raspberry Pi 5 — this alpha’s only requested test board.
  • Debian 13 “trixie” arm64, or Raspberry Pi OS 64-bit based on trixie, with a desktop session.
  • A spare SD card (recommended) and a way to flash a clean OS image onto it.
  • About 300 MB free space, plus room for any maps, ZIM files or libraries you add yourself.
  • Internet access for the install: apt downloads the Debian dependencies, which include Qt and are several hundred MB.

What is not supported

  • Pi 4 / 400 / 3, Zero 2 W and other boards are not part of this test call (see HARDWARE.md).
  • 32-bit operating systems and Debian 12 or older.
  • Windows — no build, nothing tested.
  • A Pi that already runs T.A.S.K. or R.A.I.N. — use a fresh card instead.
  • A fully offline install — not part of this alpha (see OFFLINE.md).

Install steps (volunteer test round 1)

Use a spare SD card. Do not install this on a production system or on a Pi you cannot afford to rebuild. For this round, do not connect any radio, Meshtastic node, SDR or GPS, and do not enable any transmit setting: it tests install, start and removal only. The installer in the source tree is a dry run only; installs are done by hand with apt.

These steps follow docs/VOLUNTEER-TESTING.md (the commands exercised in an emulated arm64 chroot) and the longer reference, INSTALL.md. Run one command at a time and wait for it to finish. Log in as your normal user, not root.

  1. Check your Pi

    cat /proc/device-tree/model; echo

    Expected: Raspberry Pi 5 Model B Rev …

    dpkg --print-architecture

    Expected: arm64

    grep VERSION_CODENAME /etc/os-release

    Expected: VERSION_CODENAME=trixie

    dpkg -l 'task-*' 'rain-*' 2>/dev/null | grep '^ii'

    Expected: no output. If anything is listed, stop and use a fresh card.

    If the architecture is not arm64 or the OS is not 13/trixie, stop: this alpha is not for that system.

  2. Download and verify

    Download TASK-volunteer-test-debs-20261123.zip and SHA256SUMS from the files above into your home folder, then:

    cd ~
    sha256sum -c SHA256SUMS

    Expected: OK for each file you downloaded (add --ignore-missing if you did not download them all). On any FAILED, stop and report it.

  3. Unpack and verify the ten packages

    unzip TASK-volunteer-test-debs-20261123.zip
    cd task-volunteer-test
    sha256sum -c SHA256SUMS

    Expected: ten lines ending in OK and no FAILED.

  4. Install

    sudo apt update

    Then this one command, all on one line:

    sudo apt install ./python3-task-comms_0.3.1_all.deb ./task-core_0.3.0_all.deb ./task-core-compat_0.3.0_all.deb ./task-launcher_0.3.8_all.deb ./task-console_0.2.1~alpha1_all.deb ./task-mesh_0.3.2~alpha1_all.deb ./task-maps_0.1.1_all.deb ./task-aprs_0.1.0_all.deb ./task-sdr_0.2.4_all.deb ./task-resources_0.2.4_all.deb

    apt lists what it will install and asks Do you want to continue? [Y/n]. Answer Y. Keep the full output for your report, especially any lines starting with E: or W:.

    task-mesh 0.3.2~alpha1 Recommends pulseaudio-utils (for paplay, used by the audible mesh alert), so apt will offer to install it if it is missing. See KNOWN-ISSUES.md. These packages do not enable or start any systemd service and do not flash firmware.

  5. Check the installation

    dpkg-query -W -f='${Package} ${Version} ${db:Status-Abbrev}\n' python3-task-comms task-core task-core-compat task-launcher task-console task-mesh task-maps task-aprs task-sdr task-resources

    Expected: ten lines, each ending in ii.

    sudo dpkg --verify python3-task-comms task-core task-core-compat task-launcher task-console task-mesh task-maps task-aprs task-sdr task-resources

    Expected: no output.

    task-launcher --version

    Expected: task-launcher 0.3.8

    systemctl is-enabled task-core.service

    Expected: disabled

    systemctl --user is-enabled task-mesh-service.service

    Expected: disabled. T.A.S.K. never enables services by itself; please do not enable them for this round.

  6. Try it, with no hardware attached

    Open T.A.S.K. Launcher from the desktop menu (or run task-launcher in a terminal as your normal user, not with sudo). Note for each step whether it works: the launcher window opens; the Devices tile starts T.A.S.K. Console; Mesh, Maps, Radio/APRS, SDR Studio and Library/Medical open one at a time and say that no device or content is present. Then log out and back in once and check that nothing T.A.S.K.-related started by itself.

  7. Report what happened

    Open a volunteer test report on GitHub (the template lists what to include). Redact callsigns, locations, device serial numbers, Wi-Fi names, user names and passwords first. Security or unexpected-transmit problems go through private reporting, never a public issue.

The tested-versus-untested record: sections 1, 2, 3 and 6 of the volunteer guide were run in an emulated Debian 13 arm64 chroot on a PC. A real Raspberry Pi, a real desktop session, the “try it” step, any hardware, and any Pi model other than the developer’s were not tested with these public packages.

Uninstall and rollback

This removes the T.A.S.K. packages and keeps your settings and data (/etc/task, ~/.config/task-*, ~/.local/share/task-*, maps, ZIM libraries, message history). Do not run apt-get autoremove just to uninstall T.A.S.K.

sudo apt remove python3-task-comms task-core task-core-compat task-launcher task-console task-mesh task-maps task-aprs task-sdr task-resources
dpkg -l 'task-*' python3-task-comms | grep '^ii'

Expected: no output.

The Debian packages apt installed as dependencies (Qt, numpy, …) stay installed; they do no harm. Re-flash the card if you want a completely clean system. If a new package misbehaves and you still have the previous verified .deb files, reinstall them with sudo apt-get install ./task-example_previousversion_all.deb, once per package. If the desktop is unusable, return to your previous SD card: that is the main reason to test on a spare one. Full details: INSTALL.md.

Source code and building

The complete corresponding source for every file in the release is in the repository at tag v0.1.0-alpha.1 (commit 7fd952f53d4a9d893b7996c06e3418cc1456f291), and in the two source archives above — offered next to the binaries, as GPLv3 section 6(d) describes. The tree at that tag rebuilds all ten Debian packages byte for byte with:

python3 packaging/debian/build_debs.py OUTDIR
git clone --branch v0.1.0-alpha.1 https://github.com/TASK-Preparedness/TASK.git

Optional, safe: the dry-run installer only reads hardware and OS information. From an unpacked source tree: cd installers/raspberry-pi, then /usr/bin/python3 -m task_installer detect. It installs nothing.

Known gap: the packages’ copyright files still say upstream URL TBD and their Maintainer field is the placeholder TBD-maintainer-email, which is not a contact address. They were left unchanged so the checksums match what testers were given. Bug reports go to GitHub Issues; security reports use private vulnerability reporting.
