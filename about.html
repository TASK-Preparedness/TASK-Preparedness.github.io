About: safety, license & source

T.A.S.K. is used around radios and in emergencies, so this page puts the safety rules first and the legal details right after. It summarizes the repository’s own documents; where they differ, the documents win.

Safety

⚠️ READ FIRST — experimental alpha, safety and radio warnings

  • EXPERIMENTAL ALPHA — NOT VALIDATED ON A PHYSICAL RASPBERRY PI. The public packages, installer and source tree have not been installed or accepted on a clean physical Raspberry Pi. Treat every package and every asset as experimental. Do not rely on T.A.S.K. as your only tool in a real emergency. It is not a substitute for emergency services.
  • RECEIVE-ONLY BY DEFAULT. T.A.S.K. must never transmit on any radio unless a licensed operator explicitly tells it to. Amateur transmit stays disabled until you enter your own licensed callsign. Transmit-capable features are experimental. Do not transmit if you are not licensed and allowed to. You are responsible for knowing the law where you are.
  • NO AUTOMATIC INSTALL, FIRMWARE FLASHING OR SERVICE START. The installer is a dry run only. It never flashes firmware, never takes control of your radios, and never starts anything automatically.
  • UNVERIFIED — REQUIRES PHYSICAL HARDWARE TEST. Any radio, GPS, SDR, board or feature not listed as tested in HARDWARE.md carries this label. Test on a spare SD card, never on a working system.

Read SAFETY.md and KNOWN-ISSUES.md before you install anything. See also the safety summary on this site.

Not a substitute for emergency services

If someone is in immediate danger, call 911 (or the local emergency number where you are). T.A.S.K. must not be your only plan for calling for help, navigation, or medical information. Offline medical references are not a diagnosis and do not replace a clinician.

Receive-only by default

Nothing transmits on a radio unless you explicitly tell it to. SDR Studio is receive-only. Mesh messaging over a USB Meshtastic node can send only when you compose and send a message. Radio / APRS transmit stays off until you enter your own licensed callsign and enable it. There are no automatic beacons, digipeaters or acknowledgements added by T.A.S.K.

Licenses and local law

Radio rules vary by country and change over time. In the United States, amateur transmission generally requires an FCC amateur license, and GMRS generally requires a GMRS license; FRS, MURS, CB and similar services have their own rules. A callsign prompt in the software is a guard, not a substitute for a real license or for knowing band plans, power limits and identification rules. This is practical guidance, not legal advice. See SAFETY.md.

Back up and use a spare system

Test on a spare SD card, never on a production system or the only copy of your files. Back up ~/.config/task-*, ~/.local/share/task-*, /etc/task, maps, ZIM libraries and message history before installing, upgrading or removing packages. Expect breakage.

Privacy

Mesh messages, GPS tracks, APRS and logs can reveal your location, your callsign and who you talk to. Redact them before filing a public issue.

If something seems unsafe

Stop transmitting; power down or unplug radios if needed. Take the spare card out and return to a known-good card if the system is unstable. For vulnerabilities or unexpected RF or privilege behavior, use private reporting.

Current limitations, from the release notes: no physical-Pi validation of the public packages or installer; the installer only performs a dry run; several modules still await physical hardware acceptance tests; no map, ZIM, medical or firmware content is included; the mesh alert sound is not shipped; no Windows support. Details: KNOWN-ISSUES.md.

Where the source is

  • Repository: github.com/TASK-Preparedness/TASK at tag v0.1.0-alpha.1, commit 7fd952f53d4a9d893b7996c06e3418cc1456f291.
  • Source archives attached to the release page (same tree as the tag): TASK-0.1.0-alpha.1-source.tar.gz and TASK-0.1.0-alpha.1-source.zip.
  • Build scripts for the packages are included (packaging/debian/build_debs.py, release/build_release.py and the module builders). The four vendored third-party wheels that task-mesh bundles are in mesh/packaging/vendor/, and the matching Meshtastic protocol (.proto) sources are in mesh/packaging/vendor-source/.
  • Source offer for the packages: because the Debian packages were built before the repository URL existed, their copyright files still say “upstream URL TBD” and their Maintainer field is the placeholder TBD-maintainer-email. Until a rebuild fixes that, the release notes are the source offer for those packages.
