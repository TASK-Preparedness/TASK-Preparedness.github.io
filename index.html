Open source · Offline first · Raspberry Pi

When infrastructure fails, stay connected.

An integrated emergency preparedness, communications and situational awareness platform for the Raspberry Pi, built to work in a disconnected world.

T.A.S.K. (Tactical Access Support Kit) is free-of-charge, offline-first software: mesh messaging, offline maps and GPS, amateur/GMRS radio data, a receive-only software-defined radio, and an offline library and medical reference reader. This public release is an experimental pre-release.

⚠️ READ FIRST — experimental alpha, safety and radio warnings

  • EXPERIMENTAL ALPHA — NOT VALIDATED ON A PHYSICAL RASPBERRY PI. The public packages, installer and source tree have not been installed or accepted on a clean physical Raspberry Pi. Treat every package and every asset as experimental. Do not rely on T.A.S.K. as your only tool in a real emergency. It is not a substitute for emergency services.
  • RECEIVE-ONLY BY DEFAULT. T.A.S.K. must never transmit on any radio unless a licensed operator explicitly tells it to. Amateur transmit stays disabled until you enter your own licensed callsign. Transmit-capable features are experimental. Do not transmit if you are not licensed and allowed to. You are responsible for knowing the law where you are.
  • NO AUTOMATIC INSTALL, FIRMWARE FLASHING OR SERVICE START. The installer is a dry run only. It never flashes firmware, never takes control of your radios, and never starts anything automatically.
  • UNVERIFIED — REQUIRES PHYSICAL HARDWARE TEST. Any radio, GPS, SDR, board or feature not listed as tested in HARDWARE.md carries this label. Test on a spare SD card, never on a working system.

Read SAFETY.md and KNOWN-ISSUES.md before you install anything. See also the safety summary on this site.

One platform. Essential capabilities.

These are the tiles in the T.A.S.K. launcher, in the same order, with the status of the public v0.1.0-alpha.1 packages. No module is marked stable. Public packages have not been validated on a physical Raspberry Pi.

  • Mesh Network

    Send and receive Meshtastic messages over a USB node, with desktop and audible alerts.

    Experimental · UNVERIFIED

  • Maps & GPS

    Offline maps (MBTiles you provide), live GPS position, waypoints, tracks and GPX.

    Experimental · UNVERIFIED

  • Radio / APRS

    Receive APRS through Direwolf. Transmit only when you explicitly choose to, and only if you are licensed.

    Experimental · UNVERIFIED

  • SDR

    Receive-only RTL-SDR: FM/AM/SSB, spectrum, waterfall and scanner. A physical acceptance test of SDR Studio 0.2.4 is still pending.

    Experimental · UNVERIFIED

  • Library

    Read ZIM (Kiwix), PDF, EPUB and text files you supply. No library content is included.

    Experimental · UNVERIFIED

  • Mission Planner

    Designed, not built. There is no Mission Planner in this alpha — only a launcher tile marked planned.

    Planned

  • Medical

    Offline medical reference reader for files you supply. Not a diagnosis and not a substitute for a clinician. No medical content is included.

    Experimental · UNVERIFIED

  • Weather

    Shows the status of local weather decoders and data only. It does not produce forecasts.

    Incomplete

  • Devices

    See connected devices and which app owns them.

    Experimental · UNVERIFIED

  • Files

    Opens your home folder in the desktop file manager.

    Experimental · UNVERIFIED

  • System

    Host, load, memory, storage, temperature, task-core and network status (read-only).

    Experimental · UNVERIFIED

  • App Manager

    Apps and tiles: status, enable or disable, and arrange the dashboard.

    Experimental · UNVERIFIED

Firmware Manager and a two-way Radio app are designed, not built, and have no launcher tile yet. What the status words mean is in MODULES.md; hardware verification is in HARDWARE.md. No map, ZIM, medical or firmware content is included — you supply your own, under each work’s own license.

Who this alpha is for

Volunteer testing is requested only on:

  • a Raspberry Pi 5 running Debian 13 “trixie” arm64 (or Raspberry Pi OS 64-bit based on trixie),
  • preferably on a spare SD card, not a production system.

Other boards are described in HARDWARE.md but are not part of this test call. 32-bit operating systems, Debian 12 or older, and Windows are not supported. For a parts list, see the Build List.

Receive-only by default

T.A.S.K. is designed so that nothing transmits on a radio unless you explicitly tell it to.

  • SDR is receive-only.
  • Radio / APRS transmit stays off until you enter your own licensed callsign and enable it.
  • The installer and packages do not flash firmware, change radio configuration, or start anything at boot.

You are responsible for knowing the law where you operate. Read the full safety summary.
