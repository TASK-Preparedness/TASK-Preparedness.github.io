Docs & getting started

The documentation lives in the project repository. This page is a map to it, plus the shortest safe path from download to a running launcher.

Experimental alpha — not validated on a physical Raspberry Pi. Receive-only by default. Use a spare SD card. Read SAFETY.md and KNOWN-ISSUES.md first. Windows is not supported.

Getting started

  1. Make sure your setup matches

    A Raspberry Pi 5 running Debian 13 “trixie” arm64 (or 64-bit Raspberry Pi OS based on trixie), on a spare SD card. Anything else is outside this alpha’s test call. System requirements.

  2. Download and verify

    Get the packages zip and SHA256SUMS from the download page and run sha256sum -c SHA256SUMS. Verification steps.

  3. Install by hand with apt

    One command at a time, from the verified .deb files. Install steps, or the repository’s volunteer guide.

  4. Open the launcher

    Choose T.A.S.K. from the applications menu, or run task-launcher. Nothing starts automatically and nothing transmits unless you choose to.

  5. Tell the project how it went

    Use the GitHub issue templates. Support & contribute.

After a successful install

From the project’s QUICKSTART.md. For volunteer test round 1, skip anything that needs a radio, node, SDR or GPS — that round tests install, start and removal only.

  • Mesh: plug in your Meshtastic node, open Mesh Network, pick the device. The background message service is optional; enable it yourself from Mesh → Network Status if you want messages while the window is closed. For a loud audible alert, run scripts/generate-mesh-alert.sh from the source tree (the alert sound is not shipped).
  • Maps: copy an .mbtiles file into the maps storage shown in Maps & GPS; plug in a gpsd-supported GPS for your position.
  • Library: point Library at your ZIM/PDF/EPUB folders (for example Kiwix downloads you made earlier).
  • Radio / APRS: configure Direwolf yourself first. Transmit stays off until you enter your own licensed callsign and enable it.
  • SDR Studio: plug in an RTL-SDR; it only receives.

Radios, GPS units and SDRs are listed with their verification status in HARDWARE.md. Anything not listed as tested is UNVERIFIED — REQUIRES PHYSICAL HARDWARE TEST.
